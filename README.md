# Edge Deck

Installers for Edge Deck, a touch hub for a Corsair Xeneon Edge on macOS.

One app fills the Edge with decks on a grid you arrange by touch: Spotify, Discord voice, the next event on your Google calendars, and a clock. It takes the Edge's touch away from macOS, so touching it works the decks without moving the pointer.

## Installing

Download the `.pkg` from the [latest release](https://github.com/lindor-eng/edge-deck-releases/releases/latest) and open it. It installs Edge Deck into `/Applications` and is signed and notarized.

- macOS 14.2 or later, Apple silicon or Intel.
- Touch needs Input Monitoring: switch Edge Deck on under System Settings > Privacy & Security > Input Monitoring, then reopen it.
- Spotify, Discord and Google each ask for a small developer application of your own. Each deck's section of Settings has the steps.

Installed copies check here for a newer release once a day and offer it when there is one.
